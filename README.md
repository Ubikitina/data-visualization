# Proyecto de Análisis de Datos UNSW-NB15

Este repositorio contiene el código y los scripts utilizados para el análisis del conjunto de datos **UNSW-NB15**.

## Datos Originales

Los archivos con los datos originales han sido **omitidos** de este repositorio debido a su gran tamaño, lo que hace que no sea posible subirlos a GitHub. Es por ello que la carpeta `CSV Files/` figura como vacía.

Sin embargo, el conjunto de datos completo se puede descargar desde el siguiente enlace oficial:

- [Descargar el conjunto de datos UNSW-NB15](https://research.unsw.edu.au/projects/unsw-nb15-dataset)

Una vez descargados los datos, asegúrate de colocarlos en la carpeta `CSV Files/` correspondiente dentro del proyecto para poder ejecutar los scripts de análisis.

## Estructura del proyecto

- **`CSV Files/`**: Contiene los archivos CSV con los datos de entrada.
- **`Practica.ipynb/`**: Notebook de Jupyter para el análisis.

## Cómo usar este proyecto

1. Descarga el conjunto de datos desde el enlace proporcionado.
2. Coloca los archivos de datos en la carpeta `CSV Files/`.
3. Abre el notebook para empezar el análisis.

## Requisitos

Este proyecto requiere las siguientes librerías de Python:

- pandas
- numpy
- altair
